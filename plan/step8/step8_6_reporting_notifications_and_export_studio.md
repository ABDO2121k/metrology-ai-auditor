# Step 8.6: Audit Reporting, Notifications & Export Studio

## 1. Overview & Objectives

This sub-step specifies the **Audit Reporting & Real-Time Notification Panel**, communicating directly with the **`reporting-notification`** microservice (Port 8005) and **MinIO S3 Storage** (`audit-reports` bucket).

Per procedure **PRO.MDD V23**, formal PDF audit reports must be archived in S3 storage and real-time processing events broadcast to the frontend via WebSockets.

---

## 2. WebSocket Event Stream (`ws://localhost:8005/ws/notifications`)

```
[reporting-notification Service (Port 8005)]
       │
       │ WebSocket Broadcast Channel
       ▼
[Frontend Native Hook (`src/hooks/useWebSocket.ts`)]
       │
       ├── Topic: "certificate:processed"     -> Updates Dashboard KPIs
       ├── Topic: "certificate:anomaly_flagged"-> Displays Toast Alert Badge
       └── Topic: "report:generated"          -> Enables PDF Download Link
```

---

## 3. Audit Report Generation & Export Features

1. **PDF Report Preview Modal**:
   - Renders print-ready ISO/IEC 17025 formal PDF audit report generated by `reporting-notification` service.
2. **MinIO Direct Download Button**:
   - Downloads official PDF report from MinIO bucket `audit-reports`.
3. **Audit History Log Table**:
   - Filterable audit history log displaying certificate number, validation date, validator name, AI anomaly score, and PDF download link.
